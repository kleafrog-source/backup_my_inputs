# Text Saver - Вечный буфер (Chrome Extension)

Расширение для Chrome, которое автоматически сохраняет всё, что вы вводите в текстовые поля, и позволяет восстановить удалённый текст с помощью Ctrl+Z даже после перезагрузки страницы.

## Возможности

✅ **Автосохранение по таймеру** - настраиваемый интервал сохранения (по умолчанию 1000 мс)
✅ **Лимит памяти** - ограничение размера истории (по умолчанию 100000 символов ≈ 100-200 МБ)
✅ **Фильтр страниц** - работа только на указанных доменах/страницах
✅ **Выбор элемента** - возможность указать конкретный input/textarea по class или id
✅ **Режим выбора** - кнопка для визуального выбора нужного поля на странице
✅ **История отмен** - поддержка Ctrl+Z (отмена) и Ctrl+Y/Ctrl+Shift+Z (повтор)
✅ **Персистентность** - история сохраняется в chrome.storage.local и доступна после перезагрузки

## Установка

1. Откройте Chrome и перейдите на `chrome://extensions/`
2. Включите **"Режим разработчика"** (переключатель в правом верхнем углу)
3. Нажмите **"Загрузить распакованное расширение"**
4. Выберите папку `chrome-undo-extension`
5. Расширение установлено! 🎉

## Использование

### Базовое использование
- Просто начните печатать в любом текстовом поле
- Если случайно удалили текст - нажмите **Ctrl+Z** для восстановления
- **Ctrl+Y** или **Ctrl+Shift+Z** - повтор (если отменили лишнее)

### Настройки
Кликните на иконку расширения в панели инструментов:

1. **Включить/выключить расширение** - активация/деактивация
2. **Интервал автосохранения** - как часто сохранять (мс)
   - Рекомендуется: 500-2000 мс
   - Меньше = чаще сохранение, но больше нагрузка
3. **Лимит истории** - максимальный размер истории (символы)
   - Рекомендуется: 50000-200000 (≈100-200 МБ в памяти)
4. **Разрешённые страницы** - список доменов через запятую
   - Пример: `example.com, mysite.org/page`
   - Оставьте пустым для работы на всех страницах
5. **Селектор элемента** - class или id конкретного поля
   - Пример: `.my-textarea` или `#my-input`
   - Оставьте пустым для работы со всеми полями

### Режим выбора элемента
1. Нажмите кнопку **"🎯 Режим выбора элемента"**
2. Перейдите на страницу с нужным полем
3. Кликните на целевое textarea/input
4. Селектор автоматически сохранится в настройках
5. Клик правой кнопкой отменяет выбор

## Как это работает

1. **Отслеживание элементов**: extension находит все `<textarea>`, `<input type="text">`, и `[contenteditable]` элементы
2. **Автосохранение**: при вводе текста запускается таймер, который сохраняет состояние
3. **История**: каждое изменение сохраняется в массив истории с ограничением по размеру
4. **Восстановление**: Ctrl+Z восстанавливает предыдущее состояние из истории
5. **Хранение**: история сохраняется в `chrome.storage.local` для персистентности

## Примечания

- Расширение использует примерно 100-200 МБ памяти при активной работе
- История очищается кнопкой "Очистить историю" в настройках
- Работает офлайн, не требует подключения к интернету
- Совместимо с Manifest V3 (последняя версия Chrome)
